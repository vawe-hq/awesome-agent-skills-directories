# Contributing

Open one pull request per place. Small pull requests are easy to review.

## What goes in

A place qualifies if it lists agent skills or plugins for a coding agent (Claude Code, Codex, Cursor and similar), or if it sets the rules for how skills are found. Registries, marketplaces, directories and awesome lists all count.

Include it when all of these are true:

- The link opens and the page is public.
- You can state how to get listed in exact steps, or you say plainly that the page gives none.
- You read the page that states the rules, not a summary of it.

Leave it out when the place is a single skill, a blog post, or a list that only links to other lists.

## Row format

Add a row to the table in alphabetical order by name. Fill every column:

- What it is: one short sentence.
- How to get listed: the exact steps, in the order the page gives them. Name who must submit (a person, an agent, a bot).
- Requirements: star counts, age, file layout, fields. Quote numbers as the page gives them.
- Checked: the date you read the page, as YYYY-MM-DD.

If a page blocked you, or its steps are not public, write "Unknown" and say why.

## In the pull request

Give the link to the page that states the rules and the date you read it. One or two lines are enough.

## Fixing a row

Rules change. If a row is out of date, open a pull request with the new rule, the source link and the new date. Dead places are removed.
